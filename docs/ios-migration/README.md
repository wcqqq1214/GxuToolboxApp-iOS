# iOS 迁移记录

当前构建与开发方式见[项目说明](../../README.md)及[仓库约定](../../AGENTS.md)。[RN v2.2 差距表](rn-v2.2-gap.md)记录迁移时的对照；当前行为以 Swift 源码和测试为准。旧迁移计划、提示词和交付日志可在 Git 历史中查阅。

## 保留的迁移决策

- 教务和考勤优先使用已提供的后端代理；统一认证、实验课、OA 等未覆盖的功能按需直连。工具箱分组与功能以 RN v2.2 对照，界面按 [GxuDesign](../../Packages/GxuDesign/README.md) 设计。
- 个人课表按教学班查询 `/jw/schedule/personal/reschedules`，只在匹配现安排周次、星期和节次的课次上显示「调」。对应课次的详情显示该次调课的原因和类别。旧课表缓存缺少标记和教学班 ID 时，刷新个人课表后即可读取新字段。
- `/jw/schedule/personal`、`/jw/exam`、`/jw/score` 用逻辑学期 1 / 2。迁移时实测 `term=3/12/16` 返回 400；小学期仍可用于展示。不要把这个限制套到已选课程等其他路由。
- 教务登录的 HTTP 401 不一定是凭据错误。例如「无法获取初始登录 cookie」曾随客户端 User-Agent 不同而出现，原因未证实。只有服务端明确拒绝凭据时才要求重新登录；其他失败保留账号状态。统一认证校验跟随 CAS 重定向，接受 JSON 对象或数组。
- 绩点计算在所选范围内按「课程名 + 学分」合并重复修读，取最高成绩，同分取较新的记录；成绩查询仍显示原始记录。依据为《广西大学普通本科学生课程修读、考核及成绩管理办法（2019 年修订）》第三十八条（二）；原条款针对毕业审核，工具箱把规则用于所选范围，官方结果以教务处为准。
- 节假日使用内置数据，远程 `data.json` 用于调课；作息保留原始 13 节，第 9、10 节只在显示层合并。模拟器使用 ad-hoc 签名验证 App Group 和 Keychain，真机共享能力见[设备检查清单](device-checklist.md)。
- 首页随课表、考试和实验缓存提交更新，切换标签沿用当前快照。同一账号会话内，启动时共用首次缓存读取，短时间回前台且缓存未变时沿用快照。已有快照时，课表、校历和考试在刷新收尾时一起读取。自定义课程、冲突选择和实验缓存变更仍会立即触发读取。首页与课表共用在途的开学日期、个人课表及校园日历请求。自动刷新复用两分钟内的成功结果，手动刷新跳过这段有效期。已在途的同范围请求仍可共用。
- 课表索引在课程、学期日期、校历内容、自定义课程或课程覆盖规则变更时重建。仅同步时间变更时，继续使用已有索引。

## 登录信息与使用统计

教务和考勤登录通过 HTTPS 向 `api.tool.gxutech.xyz` 提交凭据，由第三方代理访问学校系统。OA、问卷和统一认证直接访问对应学校系统。客户端将账号密码保存在本机钥匙串，用于登录流程；客户端源码不能证明代理服务器是否留存凭据。

设置页的“分享使用统计”默认关闭，旧安装没有偏好值时也保持关闭。偏好保存在共享配置中，应用启动事件和教务登录成功事件均在发送前检查该值。关闭后不再发起新的 `/event` 请求，已经发出的请求无法撤回。开关不影响登录、业务请求或用户主动提交的反馈。

启用后的事件正文只包含事件名、功能、应用版本和兼容后端的固定 `userId: "0"`，不再填入学号，也不生成安装标识。统计仍使用现有后端会话，不能据此承诺网络层匿名或删除服务器上的历史数据。隐私清单暂保留保守声明，后续结合服务端的数据处理方式核实。
