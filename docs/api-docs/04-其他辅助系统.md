# 其他辅助系统 — 接口文档

## 1. 教师信息查询 (prof)

### 基础信息

| 项目 | 内容 |
|------|------|
| **baseURL** | `https://prof.gxu.edu.cn/backend/openapi/openSearch` |
| **Content-Type** | `application/json` |
| **核心文件** | `src/js/info/teacherInfo.ts` |

### 接口

#### 1.1 按条件查询教师

- **方法**: `GET`
- **路径**: `/findByCondition`
- **Params**:
  - `xm` — 教师姓名
  - `indexSearchKey` — 搜索关键词
  - `firstLetter` — 姓氏首字母（可选）
  - `pageNum` / `pageSize` — 分页
- **返回**: `{ resData: { list: TeacherBaseInfo[] } }`

#### 1.2 按工号获取教师详细信息

- **方法**: `GET`
- **路径**: `/getTeachInfoByGH`
- **Params**: `GH` — 教师工号

## 2. OA 文件系统

### 基础信息

| 项目 | 内容 |
|------|------|
| **baseURL** | `https://oa.gxu.edu.cn/api/gxuoa` |
| **认证方式** | Bearer Token（JWT） |
| **核心文件** | `src/features/documents/api/index.ts` |

### 接口

#### 2.1 OA 登录

- **方法**: `POST`
- **URL**: `https://oa.gxu.edu.cn/api/gxuoaAuth/gxuoa/auth/login`
- **Body**:
  ```json
  { "Account": "{用户名}", "Password": "{密码}" }
  ```
- **返回**: `{ code: 200, result: { accessToken: "..." } }`

#### 2.2 获取文件列表

- **方法**: `POST`
- **路径**: `/wenjian/page`
- **Body**:
  ```json
  {
    "page": 1, "pageSize": 50,
    "keyword": "", "fileTypeId": null,
    "selectedDepartmentId": null, "keywordType": "title"
  }
  ```

#### 2.3 获取文件详情

- **方法**: `GET`
- **路径**: `/wenjian/detail`
- **Params**: `id` (文件ID), `Admin` (false)

#### 2.4 搜索文件

- **方法**: `GET`
- **路径**: `/document-search/search`
- **Params**:
  - `_wv` — 版本号
  - `searchType` — 固定 `deptDoc`
  - `keyword` — 关键词
  - `keywordType` — `title`
  - `page` / `pageSize` — 分页

## 3. 问卷系统 (wjxt)

### 基础信息

| 项目 | 内容 |
|------|------|
| **baseURL** | `https://wjxt.gxu.edu.cn/` |
| **编码** | GB2312（需 iconv 解码） |
| **核心文件** | `src/js/wjxt/api.ts` |

### 接口

#### 3.1 登录

- **方法**: `POST`
- **URL**: `https://wjxt.gxu.edu.cn/`
- **Body** (URL-encoded):
  - `__VIEWSTATE` — 固定值
  - `__VIEWSTATEGENERATOR` — 固定值
  - `userIdCard` — 用户名（身份证号）
  - `userPwd` — 密码
  - `loginsubmit` — `%B5%C7+%C2%BC`
  - `myteip` — `172.30.135.20--2`

#### 3.2 获取待办问卷

- **方法**: `POST`
- **路径**: `Wjxt_UI/qstwj.aspx`
- **返回**: GB2312 编码的 HTML，解析后得到待办文件列表

## 5. 工程训练中心 (xlzxms)

### 基础信息

| 项目 | 内容 |
|------|------|
| **域名** | `http://xlzxms.gxu.edu.cn` |
| **核心文件** | `src/js/auth/auth.ts`、`src/js/jw/course.ts` |

### 接口

#### 5.1 SSO 登录获取学生码

- **方法**: `GET`
- **URL**: `http://xlzxms.gxu.edu.cn/api/security-server/dietc/loginsso/student`
- **说明**: 通过统一认证跳转，从 response URL 中提取学生码

#### 5.2 获取 Authorization Token

- **方法**: `POST`
- **URL**: `http://xlzxms.gxu.edu.cn/api/security-server/dietc/sys/authorizing/loginsso`
- **Body**:
  ```json
  {
    "username": "{学生码}",
    "code": "ssocode",
    "queryParam": "queryParam",
    "password": "1"
  }
  ```

#### 5.3 获取个人工程训练课表

- **方法**: `GET`
- **URL**: `http://xlzxms.gxu.edu.cn/api/course-newedition-server/course/course/arrange/stuPersonalArrangeTable`
- **Headers**: `authorization: {token}`

## 6. OTA 热更新

### 基础信息

| 项目 | 内容 |
|------|------|
| **URL** | `https://file.unde.site/GxuToolApp/version.json` |
| **核心文件** | `src/core/ota.ts` |

### 接口

#### 6.1 检查版本

- **方法**: `GET`
- **URL**: `https://file.unde.site/GxuToolApp/version.json?_={timestamp}`
- **返回**:
  ```json
  {
    "beta": [ { "versionCode": 20103, "versionName": "2.1.3", "ota": [...] } ],
    "release": [ { "versionCode": 20103, "versionName": "2.1.3", "ota": [] } ]
  }
  ```
- **OTA 包结构**: `{ versionCode, versionName, bundleUrl, ... }`
