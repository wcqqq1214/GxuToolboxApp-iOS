# 统一认证系统 (CA) — 详细接口文档

## 基础信息

| 项目 | 内容 |
|------|------|
| **域名** | `https://ca.gxu.edu.cn:8443/zfca` |
| **备用域名** | `http://ca.gxu.edu.cn:81/zfim` |
| **认证方式** | CAS (Central Authentication Service) + RSA 加密 |
| **核心文件** | `src/js/auth/auth.ts` |

## 认证流程

```
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│ 获取公钥  │───▶│ 获取登录  │───▶│ RSA加密  │───▶│ 提交登录  │
│ getPubKey │    │ 页提取   │    │ 密码     │    │ +服务    │
│           │    │execution │    │          │    │         │
└──────────┘    └──────────┘    └──────────┘    └─────┬────┘
                                                      │
                                               ┌──────▼──────┐
                                               │ 获取服务Cookie│
                                               │ 或验证登录成功 │
                                               └─────────────┘
```

## 接口详情

### 1.1 获取 RSA 公钥

- **方法**: `GET`
- **URL**: `https://ca.gxu.edu.cn:8443/zfca/v2/getPubKey`
- **文件**: `src/js/auth/auth.ts:20`
- **返回示例**:
  ```json
  {
    "exponent": "10001",
    "modulus": "00b8b8b8b8b8b8b8b8b8b8b8b8b8b8b8b8b8..."
  }
  ```
- **用途**: 用于后续密码加密

### 1.2 获取登录页面（提取 execution）

- **方法**: `GET`
- **URL**: `https://ca.gxu.edu.cn:8443/zfca/login`
- **文件**: `src/js/auth/auth.ts:46`
- **处理**: 用 cheerio 解析 HTML，提取 `#fm1 > input[name="execution"]` 的 value

### 1.3 提交登录

- **方法**: `POST`
- **URL**: `https://ca.gxu.edu.cn:8443/zfca/login?service={serviceUrl}`
- **文件**: `src/js/auth/auth.ts:51`
- **Body** (URL-encoded):
  ```json
  {
    "username": "{学号/工号}",
    "password": "{RSA加密后的密码}",
    "execution": "{从上一步提取}",
    "_eventId": "submit"
  }
  ```
- **返回**: 若指定了 `service`，返回 AxiosResponse（含 Cookie）；否则检查页面是否包含 `统一身份认证-主页`

### 1.4 登录指定服务

- **方法**: `GET` → `POST`（组合调用）
- **文件**: `src/js/auth/auth.ts:69`
- **流程**:
  1. 调用 `getPublicKey()` 获取公钥
  2. 从存储中读取账号密码
  3. 调用 `login()` 并传入 `serviceUrl`
- **用途**: 为不同子系统（教务、物理实验、工程训练）获取各自的 Cookie

### 1.5 检测登录状态

- **方法**: `GET`
- **URL**: `http://ca.gxu.edu.cn:81/zfim/application/home/getYyfz.zf`
- **文件**: `src/js/auth/auth.ts:88`
- **判断**: 返回 `typeof data === "object"` 即为已登录

### 1.6 登出

- **方法**: `GET`
- **URL**: `https://ca.gxu.edu.cn:8443/zfca/logout?service=http://ca.gxu.edu.cn:81/zfim/logout`
- **文件**: `src/js/auth/auth.ts:94`
