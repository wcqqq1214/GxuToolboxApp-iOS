这是西大工具箱 App 的 OpenWiki。

所有生成的 OpenWiki 页面必须使用简体中文，包括标题、摘要、正文、表格、Mermaid 图中的说明文字、风险项、验证步骤和索引页描述。

以下内容保持原样，不做翻译或改写：

- 源码路径、文件名、路由名、命令、环境变量、配置键、数据库表名与字段名；
- HTTP 方法、URL、接口参数名、响应字段名、状态码、代码片段；
- 已有 Markdown 链接目标与锚点。

术语首次出现时可保留英文或缩写，例如 React Native、Zod、SQLite、OTA、Widget、Cookie、Hook、Adapter；之后使用一致的中文表述。文档必须以源码、测试和配置为事实依据，明确区分“已实现”“遗留代码”“已知缺口”和“规划”。
